# Women Customer Segmentation UI

A frontend UI project built using React.js for a Digital Banking Platform.

### Features
- Displays prospective women customers.
- Categorizes customers into Satisfied, Underserved, and Underbanked.
- Profile cards with images and descriptions.
- Reusable React components.

### Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3

### Project Status
Frontend UI Prototype (No backend or functional features implemented).

### Run Locally
```bash
npm install
npm run dev
```
